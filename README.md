# MageDrova

A mage path for Drova - Forsaken Kin. Rowan the Mage teaches it. Choosing it halves your maximum health and the health you gain per level (an option can turn that off). In return Rowan teaches mana regeneration and sells spells that turn you into a creature, from a water rat at level 1 to a bear at level 20. His talents make those forms stronger, longer and safer.

What changed in each version is in [CHANGELOG.md](CHANGELOG.md).

## Install

1. Install [MelonLoader](https://melonwiki.xyz).
2. Install the [Drova Modding API](https://github.com/Drova-Modding/Drova-Modding-API/releases) 0.8.0 or later.
3. Unpack `MageDrova.zip` into the game folder, so `MageDrova.dll` lands in `Mods` and the content files in `Mods/Modding_API`.

The options page (Modding tab, MageDrova) has the mage penalty switch and the key that ends a morph early.
